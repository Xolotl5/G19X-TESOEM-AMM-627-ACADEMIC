Simulador de transacciones para probar el motor de scoring y las notificaciones push (FCM).

Conexión a la API

Abre esta página vía http://127.0.0.1:8091/banco.html (servidor: php -S 0.0.0.0:8091 router.php) para evitar problemas de CORS. La URL se recuerda entre sesiones (puerto 8091: el 8090 suele estar ocupado por Wondershare).

Clientes registrados en la app (vista del banco)

  • Desde el BIT-037 esta vista exige sesión de administrador: abra la consola MIDFF.html (pestaña Clientes) para ver los ID de cliente dados de alta en la app.
Cada cliente ve en su app un ID de cliente generado al crear su cuenta. Cópielo desde la consola y péguelo aquí en el campo id_cliente para enviarle transacciones.
